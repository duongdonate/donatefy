### Task 1: Tách `features/auth` theo kiểu `AuthFlow`

**Files:**
- Create: `src/features/auth/{SignInForm,SignUpForm,Field,PasswordInput,OrDivider}.jsx`, `src/features/auth/useAuthSubmit.js`, `src/features/auth/useWander.js`
- Modify: `src/features/auth/AuthPage.jsx`

**Interfaces:**
- `Field.jsx`: `export default function Field({ id, label, error, hint, children })`: label `sr-only`, lỗi `<p id={`${id}-error`}>`, gợi ý `<p id={`${id}-hint`}>` chỉ khi không có lỗi. `export function TextInput({ id, error, hint, className = "", ...props })`: `inputCls(error)` (dời từ `AuthPage`), `aria-invalid={!!error}`, `aria-describedby` = `${id}-error` nếu có lỗi, `${id}-hint` nếu có `hint`, không thì bỏ.
- `PasswordInput.jsx`: `export default function PasswordInput(props)`: nhận như `TextInput`, tự giữ `showPass`, nút `IconButton` "Ẩn mật khẩu"/"Hiện mật khẩu" như hiện tại.
- `OrDivider.jsx`: `export default function OrDivider()`: markup `divider` hiện tại.
- `useAuthSubmit.js`: `export default function useAuthSubmit(setBusy)` → `{ formError, setFormError, send, google }`.
  - `send(fn: () => Promise<{ success, message }>)` → `Promise<{ success, message } | null>`: đang gửi thì trả `null`; không thì bật `busy`, xoá `formError`, `await fn()`. Thành công thì giữ `busy` (GuestOnly tự chuyển trang). Thất bại thì tắt `busy` và trả kết quả.
  - `google(credential)`: `send(() => loginWithGoogle(credential))`, thất bại thì `setFormError(res.message)`.
- `useWander.js`: `export default function useWander(cardRef)` → `{ x, y }`; dời nguyên hàm cùng `WANDER_MS`, `reduced`.
- `SignInForm`, `SignUpForm`: `({ username, setUsername, busy, setBusy, onToggle })`. Mỗi form tự giữ copy của mình (phần `TEXT` tương ứng), `password`, `errors`, `hasGoogle` (SignUp thêm `avatar`), gọi `validateAuth({ mode, … })`, `mapAuthError`, focus ô lỗi đầu tiên như hiện tại. Tiêu đề và câu chờ để ở `AuthPage` (theo `mode`).
- `AuthPage({ mode })`: giữ `username`, `busy`; render `mode === "login" ? <SignInForm …/> : <SignUpForm …/>`; `onToggle = (to) => navigate(to, { replace: true, state: location.state })`.
